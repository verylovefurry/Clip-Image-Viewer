# Clip Image Viewer v1.7.0

## 주요 변경

- Windows 데스크톱 앱에 맞춰 상단·하단 도구 모음, 메뉴, 설정, 목록, 레이어 패널과 동영상 컨트롤 UI를 정리했습니다.
- 빠르게 파일을 넘길 때 이전 이미지의 디코딩 결과가 현재 선택을 덮거나 이미지 표시가 실패하는 문제를 수정했습니다.
- CLIP 텍스트 개체의 저장 렌더 캐시를 직접 읽도록 개선했습니다. 캐시가 있으면 글꼴과 배치를 다시 그리지 않고 저장된 글자 픽셀을 사용합니다.
- CLIP 텍스트·벡터·일반 레이어와 컷 테두리 폴더, 이미지 소재 등의 구분 및 속성 표시를 보강했습니다.
- 벡터 필압·속도·브러시 크기 해석, 테두리, 1비트 마스크, 불투명도와 혼합 모드 처리를 개선했습니다.
- 레이어와 하위 트리 합성 캐시를 재사용하고, 목록을 부분 갱신해 반복 ON/OFF 응답성을 개선했습니다.
- 단위 테스트, 실제 CLIP 샘플 검사, 빠른 파일 이동·레이어 패널 UI 회귀 테스트를 보강했습니다.

## CLIP 레이어 중요 안내

**CLIP 레이어 ON/OFF 결과는 아직 CSP와 완전히 동일하지 않습니다.**

CSP 설치·실행이나 PSD 변환 없이 CLIP 저장 데이터를 읽지만, 톤, 일부 벡터 브러시,
테두리, 3D·전용 효과, 축소·혼합 결과에는 차이가 남아 있습니다.
텍스트 저장 캐시가 없는 파일은 글꼴 기반 재구성으로 대체될 수 있습니다.
원본 CLIP 파일은 수정하지 않습니다. 최종 출력은 CSP에서 확인해 주세요.

## 다운로드

- 설치형: `Clip-Image-Viewer-Setup-1.7.0-x64.exe`
- 포터블: `Clip-Image-Viewer-1.7.0-windows-x64-portable.zip`

포터블 버전은 파일 확장자 연결을 지원하지 않습니다.
`latest.yml`과 `.blockmap`은 자동 업데이트용 파일이며, `SHA256SUMS.txt`는 배포 파일의 검증용 체크섬입니다.
